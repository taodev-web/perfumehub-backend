# 🧴 PerfumeHub E-Commerce Backend

This is the production-ready backend for a real-world perfume e-commerce website built using Django and Django REST Framework.

---

## 🌟 Features

- ✅ User registration + profile management
- ✅ Token-based authentication
- ✅ Product listing with multiple image support
- ✅ Cart + secure checkout
- ✅ Order tracking + Stripe payment
- ✅ Email confirmation for orders + sign-up
- ✅ Refund/Return system
- ✅ Sales reporting for admin
- ✅ Stock alert email system
- ✅ UUID-based secure order tracking



---

## 🔧 Stack

- Python 3.13
- Django 5.2
- Django REST Framework
- MySQL
- Stripe API
- SMTP Email

---

## 🚀 Setup Instructions

```bash
git clone https://github.com/taodev-web/perfumehub-backend.git
cd perfumehub-backend
python -m venv env
source env/bin/activate  # or env\Scripts\activate on Windows
pip install -r requirements.txt
